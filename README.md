# AI Financial Health Coach

## Problem

Traditional banking applications are transactional and do not provide proactive financial guidance.

## Solution

AI Financial Health Coach provides:

- Financial Health Score
- Spending Insights
- Cash Flow Prediction
- Product Recommendations
- AI-powered Financial Assistant

## Technologies

- Python
- Streamlit
- Pandas
- Plotly
- Azure OpenAI

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
